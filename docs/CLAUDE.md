# docs/

A ticket-keyed specification in `docs/specifications/` merged to `main` is accepted design: read
it wherever the work needs it. It is evidence of the design, never of how the code works. Read
`docs/specifications/CLAUDE.md` for the rule's detail and for what specifications are and how
they are used.

`docs/DESIGN.md` is the project's design document, the end-to-end anchor for a body of work.
Every intent review reads it as a project goal when it exists.
