# Hotspots

These files change together in this repository. `concurrent-work.md` says how a ticket that
touches one runs.

- A release edits `charts/common/Chart.yaml`, `CHANGELOG.md`, and every
  `test/fixtures/*/Chart.yaml` and `Chart.lock` (regenerated by
  `scripts/update-fixture-charts.sh <version>`). Two release tickets never run in parallel.
- `charts/common/templates/_pod_spec.yaml.tpl`, `_pod_template_spec.yaml.tpl`, and
  `_helper_utils.yaml.tpl` feed most workload templates, so a change to one moves most
  `test/expected_output/*.yaml` files.
- `.github/workflows/release.yml` holds the test, scan, and release jobs in one file.
